# Publicar a página do minicurso

1. Envie o arquivo `index.html` para a raiz do repositório escolhido no GitHub.
2. Nas configurações do repositório, abra **Settings > Pages**.
3. Configure a publicação pela branch que contém o arquivo, selecionando a pasta raiz (`/root`).
4. Salve e aguarde a publicação. O endereço da página será informado nessa mesma tela.

A página é estática e não precisa de instalação, compilação ou dependências externas.

## Acesso institucional aos materiais

O HTML exibe as orientações, mas não autentica usuários nem restringe a pasta do Drive.
O responsável pela pasta deve configurar o compartilhamento no Google Drive para permitir
somente as contas institucionais autorizadas ou o domínio institucional, conforme as opções
disponíveis na instituição. Não use “qualquer pessoa com o link” se o acesso deve ser restrito.

Compartilhe o notebook de referência como leitor e permita a criação de cópias para que cada
estudante use **Arquivo > Salvar uma cópia no Drive** no Colab. Verifique com uma conta
institucional de aluno se ela consegue acessar e copiar o notebook.

Uma página pública no GitHub Pages pode ser vista por qualquer pessoa. A restrição institucional
dos materiais é aplicada pelo Drive, e as permissões da pasta não foram alteradas por este HTML.
